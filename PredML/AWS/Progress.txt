✅ STEP 4 — Install Docker Inside Jenkins (NOT Docker Desktop)
This is the key step to avoid slowing your machine. You will install a lightweight Docker Engine that only Jenkins uses — completely separate from Docker Desktop.

Windows — Install Docker Engine via WSL2 (recommended):

Enable WSL2 if not already:
# Run PowerShell as Administrator
wsl --install
wsl --set-default-version 2
# Restart your machine

Install Ubuntu from Microsoft Store
Open Ubuntu terminal:
# Install Docker Engine inside WSL2 (not Docker Desktop)
sudo apt-get update
sudo apt-get install -y ca-certificates curl gnupg
sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://download.docker.com/linux/ubuntu/gpg | \
    sudo gpg --dearmor -o /etc/apt/keyrings/docker.gpg
echo "deb [arch=$(dpkg --print-architecture) \
    signed-by=/etc/apt/keyrings/docker.gpg] \
    https://download.docker.com/linux/ubuntu \
    $(. /etc/os-release && echo "$VERSION_CODENAME") stable" | \
    sudo tee /etc/apt/sources.list.d/docker.list > /dev/null
sudo apt-get update
sudo apt-get install -y docker-ce docker-ce-cli containerd.io
sudo service docker start
sudo usermod -aG docker $USER

Run in CloudShell
Mac — Install Docker Engine via Colima (lightweight, no Docker Desktop):

# Stop Docker Desktop first if running
# Install Colima — lightweight Docker runtime
brew install colima docker

# Start Colima (uses much less memory than Docker Desktop)
colima start --cpu 2 --memory 4

# Verify
docker ps

Run in CloudShell
Why Colima on Mac? Docker Desktop uses 4–8GB RAM. Colima uses ~500MB. Your machine stays fast.

✅ STEP 5 — Connect Jenkins to Docker
Windows (WSL2):

Open Jenkins → Manage Jenkins → Plugins → Available
Search and install: Docker Pipeline, Docker plugin
Go to Manage Jenkins → Tools → Docker installations
Add Docker → Name: docker-wsl → Install automatically: No
Set path: /usr/bin/docker
Mac (Colima):

# Make Docker socket accessible to Jenkins
sudo ln -sf ~/.colima/default/docker.sock /var/run/docker.sock
sudo chmod 666 /var/run/docker.sock

Run in CloudShell
Then in Jenkins → Manage Jenkins → Tools → same steps as above.

PHASE 3 — Jenkins + GitHub Integration
✅ STEP 11 — Connect Jenkins to GitHub
In Jenkins → Manage Jenkins → Plugins → install GitHub plugin, Git plugin
Go to your GitHub repo → Settings → Webhooks → Add webhook
Payload URL: http://<your-local-ip>:8080/github-webhook/
Content type: application/json
Trigger: Just the push event
⚠️ For GitHub to reach your local Jenkins, use ngrok as a tunnel:

# Install ngrok — https://ngrok.com/download
ngrok http 8080
# Copy the https URL → use as webhook payload URL in GitHub

Run in CloudShell
✅ STEP 12 — Add AWS Credentials to Jenkins
Jenkins → Manage Jenkins → Credentials → Global → Add Credentials
Kind: Secret text
Add these one by one:
ID: AWS_ACCESS_KEY_ID → your access key
ID: AWS_SECRET_ACCESS_KEY → your secret key
In Jenkinsfile reference them:
environment {
    AWS_ACCESS_KEY_ID     = credentials('AWS_ACCESS_KEY_ID')
    AWS_SECRET_ACCESS_KEY = credentials('AWS_SECRET_ACCESS_KEY')
}
